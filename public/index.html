Setup guide

1 · Create the bot
Open @BotFather → /newbot → name it → copy the token into the field above.
Then send /setprivacy → pick your bot → Disable (so it can read group messages), and /setjoingroups → Enable.
2 · Create the community group
In Telegram: new message → New Group → add your bot → create. Then open the group → edit → convert to / use as a supergroup (ban/history features need a supergroup; adding admins does this automatically).
3 · Make the bot an admin
Group → Manage group → Administrators → Add admin → your bot. Enable at least Ban users and Invite users via link.
4 · Get the chat ID
Once the bot is an admin and you’ve saved the token above, the group appears in Detected groups — click it to fill the chat ID. (Send any message in the group first to trigger an update.)
